## ⚡ Key Highlights & Systems

- **🧪 Interactive Security Testing Suite:**
  - Real-time **WAF & Injection Vector Defense Sandbox** (SQLi, XSS, RCE, Path Traversal detection).
  - **HTTP Security Headers & SSL/TLS Audit** (CSP, HSTS, X-Frame-Options, Permissions-Policy scoring).
  - **Port Recon & CVE Service Scanner** (Simulated active TCP probes across Ports 21, 22, 80, 443, 445, 8080).
  - **WebCrypto Cryptographic Hasher** (Real-time client-side SHA-256 calculation via browser `window.crypto.subtle`).
- **🛡️ Password Resilience & Entropy Lab:** Live Shannon entropy calculation with brute-force crack time estimates.
- **📡 Simulated Live Packet Sniffer:** Real-time animated network packet traffic stream (TCP, DNS, TLS, ICMP, HTTP).
- **💻 Interactive CLI Terminal:** In-browser command-line interface with real-time command execution.
- **🌓 Dual Adaptive Color Systems:** Dedicated high-contrast colorways for both White Theme (Light) and Obsidian Cyber Theme (Dark).
- **📱 Ultra-Responsive Architecture:** Fluid viewport scaling across mobile phones, tablets, and desktop displays.

- **Icons:** Phosphor Icons React (`@phosphor-icons/react`)
- **Tooling:** Vite v8, ESBuild

## 🚀 Quick Start

### 1. Clone repository
```bash
git clone https://github.com/papun-00/nr-portfolio.git
cd nr-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
